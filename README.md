# Foundry Platform

Modern Y Combinator & Open Source discovery platform built with Next.js 16 and Node.js.

## Project Structure

- **`frontend/`**: Next.js 16 web application (UI, App Router, API routes, Tailwind CSS).
- **`backend/`**: YC scraper scripts and data transformation tools.

## Getting Started

Run commands directly from the root folder:

```bash
# Start frontend development server
npm run dev

# Build frontend production bundle
npm run build

# Run backend YC data scrapers
npm run scrape
```
